Rekordbox Mirrors can use the local Qualification Workspace to compare retained source facts with Spotify proposals.

```bash
djsupport sync -p "Deep House" --local-audio-audition \
  --authorize-private-source
djsupport web
```

The workspace offers four explicit outcomes: **Correct**, **Wrong — find another**, **Cannot verify**, or **Not my source**.

<Warning>
  A Qualification Draft carries no matching or playlist authority. Applying it and approving the resulting playlist remain separate operations.
</Warning>
