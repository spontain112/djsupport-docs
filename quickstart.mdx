DJ Support is designed to be operated through a local AI harness. The harness asks for one decision at a time and cannot infer permission from conversation.

<Info>
  This guide starts with one playlist and a read-only Preview. It never selects your whole library by default.
</Info>

## Before you start

- Python 3.10 or newer
- A Spotify Developer application
- A Rekordbox XML export

## Install the stable release

```bash
python3 -m pip install "djsupport @ https://github.com/spontain112/djsupport/archive/refs/tags/v0.5.0.zip"
```

<Steps>
  <Step title="Configure Spotify">
    Add your Spotify client ID and secret to `.env`. Allow this exact callback in the Spotify Developer Dashboard:

    ```text
    http://127.0.0.1:8888/callback
    ```
  </Step>
  <Step title="Export one Rekordbox library">
    In Rekordbox, choose **File → Export Collection in xml format**. Then save the reference locally:

    ```bash
    djsupport library set /path/to/library.xml
    djsupport library show
    ```
  </Step>
  <Step title="Start the guided transfer">
    Ask your local AI harness:

    > Help me transfer my first Rekordbox playlist.

    The harness calls `djsupport first-transfer --json` and returns one safe next action.
  </Step>
  <Step title="Preview before publishing">
    Select exactly one playlist. Preview may retain private matching knowledge and a resumable checkpoint, but it cannot create or update a Spotify playlist.
  </Step>
  <Step title="Review, publish, then approve">
    Inspect uncertain proposals in the Qualification Workspace. Applying a Qualification Draft requires explicit Spotify-write authorization. Approval is later and separate.
  </Step>
</Steps>
