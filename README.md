# DJ Support docs — Mintlify UI prototype

classification: public

Throwaway prototype answering: **What should DJ Support's public documentation experience look like in Mintlify?**

Three structurally different homepage directions live on one route:

- `/?variant=A` — Guided transfer
- `/?variant=B` — Control room
- `/?variant=C` — Trust first

Use the floating switcher or the left and right arrow keys. The remaining pages provide enough real content and navigation to judge each direction in context.

## Development

```bash
mint dev
```

View your local preview at `http://localhost:3000`.

This prototype is intentionally not production-ready. Capture the winning direction, then rewrite the selected design and content under production constraints.
