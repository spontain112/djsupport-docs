Read the canonical [release checklist](https://github.com/spontain112/djsupport/blob/main/docs/releasing.md), [upgrade guidance](https://github.com/spontain112/djsupport/blob/main/docs/upgrading.md), and [release records](https://github.com/spontain112/djsupport/tree/main/.release-notes).

- Latest final GitHub Release is the stable user channel.
- GitHub pre-releases are opt-in testing channels.
- Source checkouts are development software.
- Validation, version preparation, tagging, GitHub Release creation, and package publication are separate authorities.
- Public behavior changes require a linked documentation change or an explicit no-docs-impact result.
