The canonical glossary lives in [`CONTEXT.md`](https://github.com/spontain112/djsupport/blob/main/CONTEXT.md). The canonical relationship guide lives in the [domain model](https://github.com/spontain112/djsupport/blob/main/docs/domain-model.md).

<Warning>
  Do not define a second meaning for Transfer, Source Selection, Mirror, Snapshot, Preview, Qualification Draft, Provisional Playlist, Approval, or Agent Client in this repository.
</Warning>

Use domain terms in code, tests, issues, and documentation. Serialized storage names and adapter details are not domain language.
