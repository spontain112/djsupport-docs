Beatport is a secondary supported source. Use it when you want to capture a chart or label selection once; choose Rekordbox for the first guided journey.

<CardGroup cols={2}>
  <Card title="Beatport chart" icon="list-music">Creates a one-time Spotify playlist from one chart you select.</Card>
  <Card title="Beatport label" icon="tags">Creates a one-time Spotify playlist from one label selection.</Card>
</CardGroup>

<Warning>
  A one-time copy does not follow later Beatport changes. Choose ongoing sync only when you deliberately want DJ Support to maintain the relationship.
</Warning>

Ask your local AI agent to check the installed stable release before it suggests a Beatport action. Planned or pre-release features are not normal v1 user instructions.
