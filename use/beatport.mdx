Beatport is a secondary stable source path. Use it when you want to capture a chart or label selection once; choose Rekordbox for the first guided journey.

<CardGroup cols={2}>
  <Card title="Beatport chart" icon="list-music">Creates a Snapshot by default from one explicitly selected chart.</Card>
  <Card title="Beatport label" icon="tags">Creates a Snapshot by default from one explicitly selected label selection.</Card>
</CardGroup>

<Warning>
  A Snapshot is intentionally one-time. Do not opt into a Mirror unless you want later Transfers to maintain the relationship.
</Warning>

Ask your Agent Client to inspect the installed stable release's capabilities before it suggests a Beatport action. Planned or pre-release features are not normal v1 user instructions.
