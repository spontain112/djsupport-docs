DJ Support keeps remembered song matches, playlist-sync records, configuration, and recovery information in private macOS application storage. Back it up before testing a new release or changing a workflow you rely on.

## Create a backup

Ask your local AI agent to run the stable backup command and place the result somewhere separate from DJ Support's application-data directory:

```bash
djsupport backup
```

<Warning>
  A backup can contain private user-derived state. Do not commit it, attach it to a GitHub issue, or place it in a public shared folder.
</Warning>

## Restore safely

1. Stop any running DJ Support process or playlist sync.
2. Keep the current application-data directory until the restore is verified.
3. Ask your local AI agent to inspect the installed release's restore guidance.
4. Restore from a known backup, then check that DJ Support and the music library are ready before syncing a playlist.

## Before a preview release

Use the latest final release for normal work. If you intentionally test a pre-release, back up first and use copies of any Rekordbox library or audio collection involved. Never test against the only copy.
