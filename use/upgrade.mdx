Use only the [latest final GitHub Release](https://github.com/spontain112/djsupport/releases/latest) for normal DJ work. Releases marked **Pre-release** are opt-in tests.

## Before upgrading

1. Create a backup with `djsupport backup` and store it outside DJ Support's application-data directory.
2. Ask your local AI agent to read the [canonical upgrade guidance](https://github.com/spontain112/djsupport/blob/main/docs/upgrading.md) for the version you are installing.
3. Confirm the exact final-release tag before the agent changes the installation.

## After upgrading

Ask your local AI agent to check that DJ Support and your library are ready. Then [check the Spotify matches](/use/first-preview) for one Rekordbox playlist before authorizing a playlist change.

<Warning>
  Keep the previous backup until the new release has checked one playlist successfully. If the readiness check or match check fails, stop and use [Troubleshooting](/use/troubleshooting); do not keep retrying Spotify changes.
</Warning>
