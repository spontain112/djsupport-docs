You do not need to learn the command line. Give the request below to a local Agent Client that can run shell commands, read structured output, and stop for your authorization.

<Prompt description="Copy this setup request into your local Agent Client.">
Install the latest stable final release of DJ Support on this Mac. Help me configure it safely, then guide me through previewing one explicitly selected Rekordbox playlist. Use `djsupport first-transfer --json` and follow the single `next_action` it returns. Do not inspect private source data or modify Spotify without asking for the exact authorization required by that step. Never select my whole library by default.
</Prompt>

<Tabs>
  <Tab title="Claude Code">

  </Tab>
  <Tab title="Codex">

  <Tab title="Another local agent">
    Paste the same request into any local Agent Client with shell access and structured-output support. The product workflow does not change by agent.
  </Tab>
</Tabs>

<Info>
  DJ Support v1 user guidance is tested on macOS. Use the latest final GitHub Release. Pre-releases and source checkouts belong to the contributor journey.
</Info>

## What happens next

<Steps>
  <Step title="Install the stable release">
    Your Agent Client checks Python, installs the exact latest final release, and verifies that `djsupport` is available. It should not install a moving development branch.
  </Step>
  <Step title="Complete the Spotify checkpoint">
    You create or select a Spotify Developer application. Allow this exact callback URL:

    ```text
    http://127.0.0.1:8888/callback
    ```

    Your Agent Client can explain the page and verify local configuration afterward. You must handle sign-in and secrets yourself.
  </Step>
  <Step title="Export Rekordbox XML">
    In Rekordbox, choose **File → Export Collection in xml format**. Tell the Agent Client where you saved the file only when it asks for the private-source authorization needed to configure it.
  </Step>
  <Step title="Choose one playlist">
    Select one named Rekordbox playlist. DJ Support does not infer a selection and does not choose your complete library by default.
  </Step>
  <Step title="Reach Preview">
    Preview performs matching and reports proposals, but it cannot create or update a Spotify playlist. Stop here and inspect which items need attention.
  </Step>
</Steps>
