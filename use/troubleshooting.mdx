title: "Troubleshoot safely"
description: "Resolve common setup and first-sync problems without exposing private music data."
icon: "wrench"
classification: public
---

Start by asking your local AI agent to check what DJ Support is ready to do and follow the returned `next_action`. Missing input is often a normal guided state, not a failure.

<AccordionGroup>
  <Accordion title="Spotify authentication does not complete" icon="key-round">
    Confirm that the Spotify Developer application allows exactly `http://127.0.0.1:8888/callback`. `localhost` is not an alias for this callback. Keep the client secret private.
  </Accordion>
  <Accordion title="DJ Support cannot find the Rekordbox library" icon="file-question">
    Export the collection as XML, then let the local AI agent configure the selected path only after it asks permission to use the file. The path must remain local and must not appear in an issue report.
  </Accordion>
  <Accordion title="The wrong playlist was selected" icon="list-x">
    Stop. The playlist choice must be explicit. Start again with the intended playlist instead of expanding or silently reusing the previous choice.
  </Accordion>
  <Accordion title="A match looks wrong" icon="search-x">
    Do not accept it. Choose **Wrong — find another** and select the correct Spotify version yourself. A search result or high match score is only a suggestion.
  </Accordion>
  <Accordion title="A playlist sync stopped partway through" icon="rotate-ccw">
    Ask the local AI agent to inspect the saved state and resume only when the playlist and next action match the work that stopped. Do not repeat an uncertain Spotify change from memory.
  </Accordion>
</AccordionGroup>
