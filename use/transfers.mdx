DJ Support can maintain a Spotify version over time or make a one-time copy. Choose based on what you want to happen after the first playlist is created.

<CardGroup cols={2}>
  <Card title="Keep it in sync" icon="refresh-cw">
    Later syncs update the same managed Spotify playlist to follow the current Rekordbox playlist. Contributor documentation calls this ongoing relationship a **Mirror**.
  </Card>
  <Card title="Copy it once" icon="camera">
    Create a Spotify playlist from a Beatport chart or label selection as it exists now. Contributor documentation calls this one-time result a **Snapshot**.
  </Card>
</CardGroup>

## Pick the result by intent

| You want to… | Choose |
| --- | --- |
| Keep one Spotify playlist aligned with a Rekordbox playlist | Keep it in sync |
| Capture a Beatport chart once | Copy it once |
| Capture a Beatport label selection once | Copy it once |
| Maintain a Beatport selection over time | Choose ongoing sync only when you truly want it |

<Tip>
  Start with one Rekordbox playlist and check its Spotify matches. Processing the whole library requires an explicit choice because it can be expensive.
</Tip>
