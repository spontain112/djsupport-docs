A **Transfer** is one complete attempt to move an explicitly selected source into Spotify. It includes matching, publication, retained matching knowledge, playlist state when applicable, and an outcome report.

<CardGroup cols={2}>
  <Card title="Mirror" icon="refresh-cw">
    An ongoing relationship. Later Transfers update the managed Spotify playlist to match its current Rekordbox Source Selection. Rekordbox uses a Mirror by default.
  </Card>
  <Card title="Snapshot" icon="camera">
    A one-time Spotify playlist representing a Beatport chart or label Source Selection at the time of Transfer. Beatport uses a Snapshot by default.
  </Card>
</CardGroup>

## Pick the result by intent

| You want to… | Choose |
| --- | --- |
| Keep one Spotify playlist aligned with a Rekordbox playlist | Rekordbox Mirror |
| Capture a Beatport chart once | Beatport Snapshot |
| Capture a Beatport label selection once | Beatport Snapshot |
| Maintain a Beatport selection over time | Opt into a Mirror only when you truly want an ongoing relationship |

<Tip>
  Start with one selected Rekordbox playlist and Preview. Whole-library processing is deliberately explicit because it can be expensive.
</Tip>
